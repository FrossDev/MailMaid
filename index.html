🧹 MailMaid

Automatically clean your Gmail using your own rules.


  1. Click Install MailMaid above — the extension zip downloads.
  2. Unzip it anywhere (Right-click → Extract All).
  3. Open chrome://extensions, turn ON Developer mode.
  4. Click Load unpacked → select the unzipped MailMaid/ folder.
  5. Click the MailMaid icon → Sign in with Google → allow Gmail access.
Why not fully automatic? Browsers block websites from writing files outside Downloads, running PowerShell, or opening chrome://extensions for you — that would be a malware hole. The install-mailmaid.ps1 script (in this repo) does all of that because it runs on your PC, not in the browser. This page is the closest a website is allowed to get: one click to download, then the 30-second manual finish above.
